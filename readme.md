# 🎸 Nacho's Bass Store

# Descripción

**Nacho's Bass Store** es una página web creada como proyecto de práctica para una tienda ficticia de bajos eléctricos.

El objetivo principal es aplicar conocimientos de **HTML y CSS** para desarrollar una página visualmente atractiva, organizada y adaptable a diferentes tamaños de pantalla.

# Secciones

La página cuenta con:

 **Inicio:** presentación de la tienda y acceso a los productos.
 **Productos:** catálogo de bajos eléctricos organizado mediante **Flexbox**.
 **Reseñas:** opiniones ficticias de clientes organizadas mediante **CSS Grid**.
 **Contacto:** formulario para que los usuarios puedan enviar consultas.
 **Footer:** información adicional y enlaces a redes sociales.

# Diseño responsivo

La página utiliza **Media Queries** para adaptar diferentes elementos a pantallas pequeñas, especialmente el menú de navegación, la sección de reseñas y el formulario de contacto.

# Tecnologías utilizadas

HTML5
CSS3
Flexbox
CSS Grid
Media Queries
Google Fonts
Font Awesome
